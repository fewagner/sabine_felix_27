# Einladung (PowerPoint)

`Einladung_Felix_Sabine.pptx` – A4 quer, 3 Folien:
1. **Außenseite** (Flügelfalz: links Felix, rechts Sabine)
2. **Innenseite** (Brief + „Unser Tag")
3. **Infoblatt** (Location, Shuttle, Übernachtung, Dresscode, Rückmeldung + QR-Code)

Alle Texte sind normale, bearbeitbare PowerPoint-Textfelder. Offen: `[TT.MM.JJJJ]` (Rückmeldefrist).
Schriften: Cambria + Calibri (auf jedem Office vorhanden).

`build.js` erzeugt die Datei neu (`npm install && node build.js`), `assets/` enthält Aquarell-Ecken, Venue-Zeichnung, QR-Code.
